# JUN LIVE

Windows 10/11에서 사용하는 개인용 Spoon 방송 프로그램입니다. Spoon의 공식 프로그램은 아닙니다.

이 저장소는 **설치 파일과 업데이트 배포 전용**입니다. JUN LIVE의 개발 소스 코드는 공개하지 않습니다.

## 다운로드

- [JUN LIVE 0.12.1 설치 파일](https://github.com/jwonly-spn/jun-live/releases/latest/download/JUN.LIVE.Setup.0.12.1.exe)
- [버전 안내와 파일 검증 정보](https://github.com/jwonly-spn/jun-live/releases/tag/v0.12.1)

## 승인받는 방법

1. 설치 후 JUN LIVE를 실행합니다.
2. 본인의 Spoon 닉네임과 고유닉(@아이디)을 입력합니다.
3. 화면에 표시된 요청 코드를 이준님께 전달합니다.
4. 승인이 끝나면 앱에서 **승인 확인**을 누릅니다.

승인은 PC마다 따로 적용됩니다. 닉네임과 고유닉은 신청자가 직접 입력한 정보이므로, 관리자는 신청자가 전달한 요청 코드와 대조해 사용자를 확인합니다. Spoon 비밀번호와 로그인 세션은 승인 서버로 보내지 않습니다.

## Windows 베타 안내

- Windows 10/11 x64용입니다.
- 처음 실행할 때 오디오 엔진 약 105MiB를 추가로 내려받습니다.
- 현재 설치 파일에는 Windows 게시자 서명이 없습니다.
- 다른 PC의 첫 로그인·송출과 장시간 방송 검증은 아직 완료되지 않았습니다. 중요한 방송 전 소리와 채팅을 확인하세요.
- 방송 중에는 업데이트를 위해 앱을 종료하지 마세요.

배포 파일에는 설치 프로그램, 업데이트 정보, SHA-256 목록과 사용자 안내만 포함됩니다. 로그인 정보, 개인 설정과 방송 기록은 공개하지 않습니다.

GitHub가 자동으로 제공하는 **Source code** 압축 파일에는 이 저장소의 안내문만 들어 있습니다. JUN LIVE의 개발 소스가 아닙니다.
