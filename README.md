# JUN LIVE

Windows에서 사용하는 Spoon 방송 프로그램입니다.

이 저장소는 **설치 파일과 업데이트 배포 전용**입니다. JUN LIVE의 개발 소스 코드는 공개하지 않습니다.

## 다운로드

첫 Windows 베타 배포를 준비하고 있습니다. 현재 공개된 설치 파일은 없습니다. 검증을 마치면 이 저장소의 [Releases](https://github.com/jwonly-spn/jun-live/releases)에 설치 파일과 변경 사항을 게시합니다.

배포할 파일은 Windows 설치 프로그램, 업데이트 정보, 파일 검증용 SHA-256 목록, 사용자 안내입니다. 개발 프로젝트, 로그인 정보, 개인 설정과 방송 기록은 포함하지 않습니다.

GitHub에서 자동으로 제공하는 “Source code” 압축 파일에는 이 저장소의 안내문만 들어갑니다. JUN LIVE의 개발 소스가 아닙니다.

JUN LIVE는 Spoon의 공식 프로그램이 아닙니다.
